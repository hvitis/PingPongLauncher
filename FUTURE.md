# Future iterations

These are proposed improvements. They are not implemented or verified by this repository.

| Priority | Iteration | Purpose | Evidence needed before calling it complete |
|---|---|---|---|
| 1 | Complete one instrumented physical build | Close the largest documentation gaps | Per-joint screw list, shaft dimensions, fitted bearings, photos, measured motor currents, and a recorded single-ball trial |
| 1 | Add wheel, gear, and feeder guards | Reduce access to pinch points | Full tilt-range clearance, secure attachment, inspection access with power disconnected |
| 1 | Finalize the DC system | Replace the source power estimate with a measured design | Running/start/stall-current data, suitable supply, rated switch/connectors, protection, terminal diagram, strain relief |
| 2 | Publish a dimensioned assembly drawing | Make fastener selection and part orientation repeatable | Part IDs, an exploded drawing, insert locations, screw lengths, and bearing seats verified on a build |
| 2 | Resolve the outlet and stopper revision | Reduce double feeding and jams | Measured ball clearance, stopper geometry, and repeated feed trials with a recorded sample size |
| 2 | Use replaceable, balanced wheel tires | Make wear parts repeatable | Specified rubber thickness, concentric mounting, runout measurements, retention, and endurance observations |
| 3 | Add wheel-speed feedback | Make settings repeatable across load and supply changes | Tachometer measurements, a calibrated speed range, and stable closed-loop control |
| 3 | Add jam detection and a feed timeout | Stop the feeder when a ball blocks the path | Current or motion sensing, a defined timeout, guarded trials, and power-off recovery instructions |
| 3 | Create a repeatable print profile per printer | Reduce trial and error | Material, orientation, supports, fit coupons, measured filament use, and actual print time |
| 4 | Add measured practice presets | Turn anonymous knob positions into useful drills | Wheel rpm, feeder interval, angle, observed placement, and clear repeatability limits |
| 4 | Refine the assembly wizard after a build | Replace illustrative motions with proven assembly views | Photos at each joint, validated insertion order, accessible text, and contributor review |

Avoid promising a ball rate, range, spin setting, print time, price, or durability target before measurements support it.
